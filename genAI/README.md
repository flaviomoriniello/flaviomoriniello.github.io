# AI Image Generation — Illustrated v2

Nuova versione con dieci copertine originali generate con ImageGen, una per lezione, con palette crema, viola, lilla e antracite ispirata alle lezioni 07 e 09.

Carica il contenuto di questa cartella nella radice del repository GitHub, incluso index.html, .nojekyll, assets e tutte le dieci cartelle delle lezioni. Attiva GitHub Pages dal branch e dalla cartella radice usati dal repository.

Apri index.html per consultare il corso. Le copertine sono in assets/covers; i prompt sono in COVER_PROMPTS.json. Contenuti delle lezioni, navigazione e salvataggio nel browser sono quelli della versione precedente.
