## Metodo di generazione

Le immagini sono state generate con il generatore integrato di immagini, usando integralmente il prompt specifico di ogni file Markdown. A ogni prompt sono stati aggiunti soltanto vincoli comuni di uniformità: uso didattico universitario, composizione pulita 16:9, sfondo neutro chiaro ove appropriato, palette blu/arancio, assenza di testo, formule, marchi, filigrane ed elementi estranei.
